## 🧠 Overview

**NovaCraft** is a **Full Stack (FS)** modern e-commerce boutique platform built using **JavaScript (JS) / React / Next.js** as the core technology stack.  
Its primary goal is to provide a high-conversion, architectural minimalist shopping experience for **apparel, accessories, and niche fragrances**, reverse-engineered from global benchmarks like **[COS](https://www.cos.com/)** and tailored natively for **Persian (RTL)** and **Mobile-First** user journeys.

> 🧩 Designed with clean architecture, CSS logical properties, modular design tokens, and frictionless one-page checkout.

---

## 🌟 Key Capabilities & Architectural Highlights

- **Scandinavian Minimalist Design DNA:** High-contrast pigment black and alabaster off-white palette, generous negative space, and hairline borders inspired by COS.
- **RTL-Native Layout:** Built using modern CSS logical properties (`margin-inline`, `padding-inline`, `inset-inline`) with standard Persian typography (**Vazirmatn**).
- **Mobile-First Ergonomics:** Thumb-zone optimized UI, sticky bottom action bar, and gesture-driven **Quick Add Bottom Sheets** for instant size/volume selection.
- **Dual-Attribute Matrix Engine:**
  - *Apparel:* Interactive color swatches and dynamic sizing guide (38–44).
  - *Fragrance:* Volume switcher (50ml / 100ml) with dynamic pricing, longevity indicators, and pyramid olfactory notes (Top/Heart/Base).
- **Inventory & Checkout Flow:** Real-time stock status monitoring, zero-friction guest checkout, and seamless integration with Shetab payment gateways.
